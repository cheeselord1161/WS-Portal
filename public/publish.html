ORGANIZATIONS Create an organization

An organization is a shared page for a company, team or community. You become its owner and can add admins and editors who publish together.

STEP 1 Create a project

This creates a public page at /p/your-project. The URL is permanent, so pick a clear name.
If a project page already exists (for example because it was imported), you can claim it. Claiming gives you publishing rights to that page.

STEP 2 Publish a release

Choose one of your project pages, then write or import a release. Drafts are saved but never shown publicly or in the sitemap until you publish them.
